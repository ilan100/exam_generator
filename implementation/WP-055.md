# WP-055 — Globus Pallidus Classification-Ambiguity Investigation

## 1. Objective

WP-054 permanently implemented the narrow identity-first strategy for:

```text
גרעיני הבסיס + Caudate Nucleus
    → IDENTITY_FIRST

גרעיני הבסיס + Nucleus Accumbens
    → IDENTITY_FIRST
```

while keeping:

```text
גרעיני הבסיס + Globus Pallidus
    → DEFAULT
```

The latest live verification showed that Globus Pallidus remains an unresolved generation problem:

```text
Globus Pallidus
    DEFAULT
    ↓
3 attempts
    ↓
3 grounding failures
```

The failures belong to the previously observed:

```text
classification / membership ambiguity
```

family.

WP-055 is therefore a **diagnostic investigation**.

Its objective is:

> **Determine why Globus Pallidus repeatedly produces classification/membership-style questions that fail grounding, identify the actual failure mechanism, and establish the smallest justified architectural direction for resolving it.**

This WP must **not** immediately implement a production fix.

# 8. Core Diagnostic Question

The investigation must answer:

> **What specifically causes Globus Pallidus questions to be classified as acceptable-looking classification/membership questions by generation but rejected by the grounding validator?**

Possible causes include, but are not limited to:

```text
A. The evidence supports a relationship but not the membership claim.
B. The model converts a local relationship into a broader class-membership statement.
C. Retrieval provides evidence about the surrounding structure but not the exact proposition.
D. The target's factual role is represented incorrectly.
E. Competitor selection encourages an invalid classification distinction.
F. Prompt wording encourages category-level questions.
G. Grounding validation correctly rejects an otherwise plausible-looking question.
H. The generated proposition is valid medically but unsupported by the supplied authority.
I. Multiple causes interact.
```

Do not assume which one is correct before analysis.

---

# 9. Required Diagnostic Principle

The investigation must distinguish:

```text
FACTUAL TRUTH
```

from:

```text
SOURCE-SUPPORTED TRUTH
```

The project requires the latter.

A statement can be medically true and still be invalid for generation if the authoritative student-summary evidence does not support the exact proposition.

Therefore:

```text
"probably true"
```

is not sufficient.

The question must be grounded in the project's source authority.

# 12. Build a Failure Taxonomy

For each failed Globus Pallidus question, classify the failure into the smallest useful category.

Suggested taxonomy:

```text
CLASSIFICATION_MEMBERSHIP
    The question asserts membership/classification
    that the evidence does not support.

RELATIONSHIP_TO_MEMBERSHIP
    The evidence supports a relationship between structures,
    but the question transforms it into class membership.

CATEGORY_LEVEL_FACT
    The evidence supports a broader category but not
    the target-specific proposition.

TARGET_IDENTITY
    The generated proposition confuses the target with
    a parent, child, sibling, or related structure.

EVIDENCE_GAP
    Retrieval does not contain sufficient evidence for
    the proposition.

COMPETITOR_PROBLEM
    Distractor/competitor construction creates the
    unsupported distinction.

PROMPT_PROBLEM
    The generation instructions encourage the invalid
    question shape.

VALIDATOR_PROBLEM
    The validator rejects a proposition that is actually
    supported by the authoritative evidence.

OTHER
    Only when none of the above applies.
```

Use the smallest category that explains the actual failure.
