# WP-060 — Cross-Category Target Inventory Feasibility and Evidence-Gap Analysis

## 1. Objective

WP-059 completed the remaining-target candidate discovery analysis and reached a deliberate negative result:

```text
No Tier A candidate found.
No new controlled IDENTITY_FIRST experiment is currently justified.
```

The existing three permanent `IDENTITY_FIRST` mappings remain unchanged:

```text
גרעיני הבסיס + Caudate Nucleus
    → IDENTITY_FIRST

גרעיני הבסיס + Nucleus Accumbens
    → IDENTITY_FIRST

גרעיני הבסיס + Globus Pallidus
    → IDENTITY_FIRST
```

WP-059 also exposed the next evidence limitation:

```text
20 canonical categories
        ↓
3 categories have deterministic target inventories + historical pilot evidence
        ↓
17 categories have neither
        ↓
no target-level historical strategy evidence
        ↓
no meaningful candidate discovery possible for those categories
```

WP-060 must therefore investigate the **evidence-coverage bottleneck**, not manufacture another `IDENTITY_FIRST` experiment.

The architectural question is:

> **Can the remaining 17 categories obtain a reliable, deterministic target/concept inventory without changing factual source authority or introducing unnecessary production complexity, and what is the smallest safe next step for collecting strategy evidence from those categories?**

This is a feasibility and architecture-analysis WP.

It is **not** permission to change production target planning yet.

---

# 2. Why WP-060 Is Needed

WP-059 demonstrated that the current evidence base is asymmetric.

The project can perform target-level strategy analysis for:

```text
גרעיני הבסיס
אספקת דם
מסילות עצביות
```

because these categories have deterministic concept inventories and historical pilot records.

For the other 17 canonical categories, WP-059 found:

```text
no deterministic target population
+
no historical pilot-generation evidence
```

Therefore:

```text
no candidate
```

does not mean:

```text
IDENTITY_FIRST is inappropriate
```

It means:

```text
there is currently no target-level evidence from which
to evaluate the strategy.
```

This distinction is architecturally important.

# 13. SAFE_GENERALIZATION_POSSIBLE

Use:

```text
SAFE_GENERALIZATION_POSSIBLE
```

only if:


# 16. SOURCE_STRUCTURE_INSUFFICIENT

# 17. LLM_TARGET_PLANNING_ONLY_CURRENTLY

# 29. Important Architectural Principle

Do not optimize for:

```text
maximum deterministic coverage
```

Optimize for:

```text
reliable target selection
+
source-grounded generation
+
predictable behavior
+
minimal architectural complexity
```

A hybrid architecture may be the correct answer:

```text
deterministic target inventory
    where source structure supports it

LLM target planning
    where source structure does not support safe extraction
```

Do not force one mechanism across all categories.

---

# 30. Relationship to Strategy Selection

WP-060 must explicitly explain:

```text
target inventory
    ↓
available target population
    ↓
historical generation evidence
    ↓
strategy analysis
    ↓
controlled experiment
```

Without a stable target population, the project cannot systematically determine whether:

```text
DEFAULT
```

or:

```text
IDENTITY_FIRST
```

or another strategy is appropriate for a target.

This is why WP-060 addresses an evidence bottleneck rather than directly changing generation strategy.
