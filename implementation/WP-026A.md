THE CASE TO INVESTIGATE
============================================================

WP-026 human review found an accepted question in:

    category: מערכת העצבים ההיקפית

Target factual meaning:

    The peripheral nervous system includes/divides into
    the autonomic and somatic nervous systems.

The accepted question was approximately:

    Which of the following systems is part of the
    peripheral nervous system?

Answers included:

    Somatic nervous system        <-- marked correct
    Central nervous system
    Autonomic nervous system      <-- marked incorrect
    Parasympathetic ...

The target/evidence itself says BOTH:

    somatic

and:

    autonomic

belong to the PNS.

Therefore the question appears to have at least two defensible correct
answers.

Nevertheless:

    GroundingValidator passed it
    MCQValidator passed it
    CategoryValidator passed it
    QualityValidator passed it

and the question entered the clean exam.

This is a FALSE ACCEPTANCE and therefore potentially more serious than an
ordinary generation exhaustion.

PART 3 — TRACE MCQ VALIDATION
============================================================

Inspect MCQValidator's:

- prompt
- input context
- response model
- implementation
- tests

Determine:

1. Does MCQValidator receive factual evidence?

2. If not, what information does it use to decide whether there is exactly
   one best answer?

3. Does its prompt explicitly require evaluating EVERY answer option?

4. Does it explicitly ask:

       Could any distractor also correctly answer the question?

5. Does it have factual evidence sufficient to determine that?

6. Does its result model provide only:

       valid + reason

   or more structured per-option analysis?

7. Why did it approve this particular question?

Distinguish between:

    structural MCQ validity

and:

    factual one-best-answer validity.

For example, a question can LOOK structurally like a good four-option MCQ
while still having two factually correct answers.

Determine which of those responsibilities MCQValidator currently implements.

============================================================
PART 7 — ARCHITECTURAL RESPONSIBILITY
============================================================

Determine where the invariant should live:

    "Exactly one answer is factually correct according to the supplied
     authoritative evidence."

Evaluate at least these alternatives:

OPTION A — Generation prompt only

Strengthen generation so it must never use another evidence-supported sibling
fact as an incorrect distractor.

Evaluate whether this is sufficient as a correctness guarantee.

OPTION B — MCQValidator

Give MCQ validation enough evidence/context to independently verify that
exactly one answer is correct.

Evaluate architectural fit and likely cost.

OPTION C — GroundingValidator

Expand grounding from:

    intended answer is supported

to something like:

    intended answer is supported
    AND
    no distractor is also supported.

Evaluate whether this is conceptually grounding responsibility.

OPTION D — Deterministic check

Determine whether a non-LLM check could reliably establish this invariant.

Be realistic: semantic factual equivalence may make this difficult.

OPTION E — Generation improvement + independent validation

Generation reduces occurrence probability, while an independent validator
prevents false acceptance.

OPTION F — Other

If the existing architecture suggests a cleaner solution, explain it.
