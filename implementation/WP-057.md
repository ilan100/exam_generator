# WP-057 — Permanent Globus Pallidus Identity-First Mapping

## 1. Objective

WP-056 completed the controlled experiment for:

```text
Category:
גרעיני הבסיס

Target:
Globus Pallidus
```

The experiment compared:

```text
CONTROL:
current DEFAULT behavior

EXPERIMENT:
temporary reverse-framed identity instruction
```

using the real production generation pipeline, real OpenAI API, real validators, and the existing three-attempt budget.

The result was:

```text
CONTROL
    0 / 7 primary-success attempts
    1 / 3 rounds eventually accepted

EXPERIMENT
    3 / 4 primary-success attempts
    3 / 3 rounds eventually accepted
```

The experiment also produced:

```text

among identity-shaped attempts
```

and no membership-classification attempts under the experimental condition.

The architecture review of WP-056 therefore approved the next step:

> Permanently add `גרעיני הבסיס + Globus Pallidus` to the narrow `IDENTITY_FIRST` mapping using the existing WP-054 strategy infrastructure.

WP-057 implements exactly that decision.

This is a **narrow production implementation**.
