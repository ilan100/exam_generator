# 1. Objective

Design the next-generation distractor-generation architecture.

This WP produces an architectural proposal.

It does NOT implement it.

---

# 2. Background Investigation

Study the existing generation pipeline.

Document precisely:

- how distractors are currently requested;
- how QuestionTarget influences generation;
- where distractor decisions are currently made;
- where diversity information is available;
- where evidence is available;
- what information the application already knows before generation.

Do not modify code.

---

# 3. Failure Analysis

Using:

- WP-027
- WP-028
- previous evaluation reports

classify distractor failures.

Examples include:

- another answer also correct;
- hierarchy ambiguity;
- multiple valid members;
- functional overlap;
- wording ambiguity;
- synonym confusion;
- broad relationship;
- weak distractor;
- implausible distractor.

Estimate which categories dominate.

Do not generate new questions.

Use existing reports whenever possible.

---

# 4. Distractor Taxonomy

Design a taxonomy of distractor strategies suitable for neuroanatomy.

For each strategy describe:

- definition;
- educational purpose;
- expected difficulty;
- advantages;
- risks;
- examples.

Possible candidates include:

- sibling structure;
- parent;
- child;
- neighboring anatomy;
- opposite function;
- opposite location;
- developmental-stage confusion;
- pathway confusion;
- blood-supply confusion;
- terminology confusion;
- anatomical-orientation confusion.

Do not assume these are final.

Propose additional strategies if justified.
