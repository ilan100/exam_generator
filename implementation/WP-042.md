# WP-042 — Generation Failure Analysis for `גרעיני הבסיס`

## 1. Objective

WP-041 successfully established the deterministic English-first language policy.

However, the WP-041 live pilot showed a material acceptance regression:

```text
WP-040: 11/12 accepted
WP-041:  9/12 accepted
```

The regression was concentrated in:

```text
Category:
גרעיני הבסיס

Problematic concept:
Corpos Striatum
```

WP-041 also showed that English-first improved concept rotation and achieved 100% target alignment.

Therefore, **do not change the English-first policy at this stage**.

The purpose of WP-042 is to determine the actual cause of the acceptance regression.

---

# 2. Critical Architectural Question

We need to answer:

> **Is English-first itself causing the new generation failures, or is English-first exposing an existing weakness in the `Corpos Striatum` evidence/generation path?**

There are three possible explanations.

### Hypothesis A — English-first causes the problem

The additional requirement:

```text
Target language = English
```

may make generation harder when the underlying evidence is predominantly Hebrew or structurally weak.

Possible chain:

```text
Corpos Striatum
        ↓
English target required
        ↓
evidence is difficult to use in English
        ↓
grounding / quality / other validation failure
        ↓
3 attempts exhausted
```

### Hypothesis B — Evidence quality is the real problem

`Corpos Striatum` may already have unusually poor evidence.

Possible chain:

```text
Corpos Striatum
        ↓
weak / difficult evidence
        ↓
generation failures
```

English-first may simply have made the problem more visible.

### Hypothesis C — Constraint interaction

The problem may only appear because several constraints now operate simultaneously:

```text
evidence quality
+
English-first
+
target identity
+
grounding
+
MCQ
+
quality
+
category
        ↓
candidate rejected
```

WP-042 must determine which explanation is supported by actual attempt-level evidence.
