# WP-053 — Identity-First Generation Controlled Experiment

## 1. Objective

WP-052 established a strong historical signal that:

```text
Caudate Nucleus
    PROPERTY = 0/8
    IDENTITY = 4/4

Nucleus Accumbens
    PROPERTY = 1/8
    IDENTITY = 3/3

Globus Pallidus
    PROPERTY = 1/4
    IDENTITY = 3/4
```

However, these identity successes were retrospective. In many historical rounds the system reached an identity question only after property attempts had already failed.

Therefore WP-052 did **not** authorize production implementation.

WP-053 is the controlled experiment required to answer the causal question:

> **If Caudate Nucleus and Nucleus Accumbens are explicitly instructed to attempt an identity-based question on the first attempt, does first-attempt acceptance improve without reducing accepted output or violating existing validation rules?**

This WP is:

```text
EXPERIMENTAL
PROTOTYPE-ONLY
NO PRODUCTION IMPLEMENTATION
```

# 9. Experimental Principle

The experiment must test:

```text
IDENTITY-FIRST
```

not:

```text
IDENTITY-ONLY
```

The distinction is important.

Identity-first means:

```text
Attempt identity strategy first.
```

It does not necessarily mean:

```text
Never generate a property question.
```

The experiment must define exactly what happens if the first identity attempt fails.

The default should remain the existing retry budget and existing validation behavior unless a controlled experimental reason requires otherwise.

Do not silently invent new retry semantics.

# 18. Identity Question Definition

For the experiment, classify an identity question as a question whose correct answer is determined by the target's identity/name rather than by a distinguishing factual property.

Examples of identity structure may include:

```text
Which of the following is Caudate Nucleus?

Which of the following is also known as Nucleus Accumbens?
```

These are examples of structure, not mandatory wording.

The generated question must use the existing question schema and terminology.

---

# 19. Property Question Definition

A property question depends on an evidence-supported target-specific fact such as:

```text

membership
association
```

The property must be supported by the authoritative evidence and must not merely be a category-level fact.
