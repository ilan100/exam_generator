# WP-056 — Globus Pallidus Identity-First Controlled Experiment

## 1. Objective

WP-055 completed the diagnostic investigation of the repeated Globus Pallidus generation failures.

The current production state is:

```text
גרעיני הבסיס + Caudate Nucleus
    → IDENTITY_FIRST

גרעיני הבסיס + Nucleus Accumbens
    → IDENTITY_FIRST

גרעיני הבסיס + Globus Pallidus
    → DEFAULT
```

WP-055 established that the three fresh Globus Pallidus failures were not caused by:

```text
retrieval inability
competitor selection
grounding-validator false positives
missing prompt guidance
```

Instead, the model repeatedly selected a bare classification/membership framing even though the prompt already explicitly discourages that framing.

WP-055 also found a historical pattern:

```text
reverse-framed identity questions
    → repeated successful Globus Pallidus outcomes
```

The specific successful shape is:

```text
Which of the following IS Globus Pallidus?
```

WP-056 therefore performs a **controlled experiment** to determine whether this specific reverse-framed identity strategy improves Globus Pallidus generation relative to the current `DEFAULT` behavior.

### Critical boundary

WP-056 is an experiment only.

It must **not**:

```text
add Globus Pallidus to the permanent IDENTITY_FIRST mapping
modify production prompts
modify QuestionGenerator production behavior
modify QuestionProducer
modify validators
modify retrieval
modify schemas
modify retry count
modify target selection
change source authority
```

A positive result is evidence for a future architectural decision, not permission to implement the strategy.

The exact question is:

> **Does explicitly encouraging reverse-framed identity generation improve Globus Pallidus generation quality and acceptance relative to the current DEFAULT strategy?**

# 6. Experimental Condition

The experimental condition should add a narrow, temporary instruction equivalent in intent to:

```text
For this target, prefer a reverse-framed identity question
that asks which answer choice IS the named target.

Example:

Do not replace this with a broader category-membership question such as:
"Which structure is part of the basal nuclei?"

The identity framing is a preference, not an unconditional validity override.
All grounding, uniqueness, target identity, category, quality,
and other existing constraints remain mandatory.
```

The exact wording may be implemented by Claude using the existing experimental mechanism/pattern, but the semantic intent must remain unchanged.

# 13. Important Distinction: Identity vs Membership

The experiment must classify generated questions semantically.

### Identity

Example:

```text
Which of the following IS Globus Pallidus?
```

This establishes which answer represents the named target.

### Membership

Example:

```text
Which structure is part of the basal nuclei?
```

This asks about group membership.

Membership is **not** an identity-first success.

A question must not be counted as experimental success merely because:

```text
correct answer = Globus Pallidus
```

If the proposition is still:

```text
Globus Pallidus is a member of the basal nuclei
```

then it remains the previously observed membership problem.

Do not claim statistical significance from a small engineering sample unless the collected data actually justify it.

# 27. What Counts as Strong Evidence

Strong evidence would look like:

```text
CONTROL:
mostly membership/property attempts
low valid identity acceptance

EXPERIMENT:
consistently reverse-framed identity
higher valid identity acceptance
```

especially if the effect is repeated across independent rounds.

Weak evidence:

```text
CONTROL:
1 failure

EXPERIMENT:
1 success
```

This can support:

```text
promising
```

but not:

```text
proven
```

---

# 28. What Counts as Experimental Failure

The experiment fails to support the hypothesis if:

```text
experimental instruction does not reliably change
question shape
```

or:

```text
identity-shaped questions are still rejected at similar rates
```

or:

```text
experimental performance is not meaningfully better than control
```

or:

```text
the experimental instruction introduces new validation failures
```

Do not force a positive interpretation.
