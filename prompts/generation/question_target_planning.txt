Genuine diversity is required (read carefully):
- Two targets are NOT sufficiently distinct if they differ only in wording or phrasing. For example, "What does the spinothalamic tract transmit?" and "Which sensory modalities are carried by the spinothalamic tract?" test the same target.
- Two targets are NOT sufficiently distinct if one is simply the question/answer of the other reversed. For example, "Which tract carries pain and temperature?" and "What does the spinothalamic tract carry?" test the same target from different directions.
- Two targets are NOT sufficiently distinct if they test the same structure and the same property, even if phrased differently - for example, two targets both about "hippocampus and memory" are the same target no matter how each is worded.
- Two targets are NOT sufficiently distinct if they test the same narrow relationship approached from different directions - for example "Where is structure X located?" and "Which structure is located at Y?" when both test exactly the same location relationship.
- Prefer targets that differ in concept, structure, function, pathway, relationship, mechanism, or anatomically/clinically relevant distinction, when the supplied evidence actually supports that difference.
